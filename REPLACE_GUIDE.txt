========================================================
部署步骤（在你的项目根目录执行）
========================================================

1. 停止正在运行的 uvicorn（Ctrl+C）

2. 备份旧文件（可选但推荐）：
     copy models\feed_models.py models\feed_models.py.bak
     copy services\recommendation_engine.py services\recommendation_engine.py.bak

3. 用上面的文件覆盖（直接同名粘贴/替换内容）

4. 因为 Feed 模型加了字段（dm_pct/adf_pct/tdn_pct/ca_pct/p_pct/extra_json），
   必须重建数据库：
     del data\simmental_nutrition.db
     python init_project.py

5. 导入原料（把 原料含量.xlsx 放到项目根目录）：
     python import_feeds.py

6. 重启服务：
     uvicorn main:app --reload --port 8000

7. 打开 http://localhost:8000/docs
   → POST /api/v1/feeds/  试录一条原料
   → POST /api/v1/recommend/  用下面的 body 测试配方优化：

----- recommend 请求示例 -----
{
  "targets": {
    "cp_pct": {"min": 14, "max": 18},
    "me_mj_kg": {"min": 9, "max": 12},
    "ca_pct": {"min": 0.6, "max": 1.2}
  },
  "candidates": [
    {"name": "玉米", "max_ratio": 60},
    {"name": "豆粕（43%）", "max_ratio": 30},
    {"name": "麦麸", "max_ratio": 30},
    {"name": "苜蓿（初花期）", "max_ratio": 40},
    {"name": "石粉（碳酸钙）", "max_ratio": 3}
  ],
  "total_weight": 100
}
----- /recommend -----
